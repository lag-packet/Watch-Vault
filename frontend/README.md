# Watch Vault Frontend

Next.js 15 frontend initialized with TypeScript, React, Tailwind CSS, shadcn/ui-style components, TanStack Query, Axios, Lucide icons, Vitest, Testing Library, and Playwright.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm test` runs Vitest.
- `npm run e2e` runs Playwright tests.
